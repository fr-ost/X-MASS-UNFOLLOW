X limits accounts that follow or unfollow too quickly, so the extension works at a human pace:

• Safe: 15-35 seconds apart, a break every 30, up to 250 a day
• Balanced (recommended): 8-20 seconds apart, a break every 50, up to 400 a day
• Fast: 4-10 seconds apart, a break every 80, up to 1,000 a day (for X Premium)
• Custom: set your own delays, breaks and daily limit

The daily limit is a rolling 24-hour window: when it's reached, the run rests and continues on its own. If X asks you to slow down, it backs off automatically. If X asks you to verify your account, it stops and waits for you. Emergency stop: Alt + Shift + S.

No tool can guarantee that X will never rate-limit or restrict an account. Reasonable limits and following X's rules keep the risk low.

How do I see who doesn't follow me back on Twitter (X)?
Install the extension, open x.com and press "Scan my following". Every account that doesn't follow you back is listed under "Don't follow back".

How do I see who unfollowed me on X?
Scan once to save your followers, then scan again any time later. The Followers page lists everyone who unfollowed you since the previous check, with dates.

How do I unfollow everyone on X at once?
After a scan, choose "Unfollow all...". Your whitelist and Keep rules still apply, and you can pause or stop at any time.

How do I unfollow inactive accounts on Twitter?
Open the Inactive tab on the Following page, run the last-active check, pick how long they've been quiet (30 days to a year+), select them and press "Unfollow selected".

Is it really free? Are there limits?
Yes, it's free. There's no subscription, no sign-up and no cap on how many accounts you can process. The only limits are the daily limits you choose to keep your account safe.

How many accounts can I unfollow per day?
X commonly limits around 400 follow/unfollow actions a day on a free account and about 1,000 with X Premium. The default limit is 400; when it's reached, the run continues automatically as the 24-hour window frees up.

Is it safe for my account?
It works at a human pace with random delays, breaks and a daily limit, backs off when X asks, and stops if X asks you to verify your account. It never asks for your password.

Can I undo an unfollow?
Yes. Open History, select the accounts and press "Follow again".

Will it unfollow my friends or mutuals?
Only if you choose "Unfollow everyone". Whitelisted accounts and accounts covered by your Keep rules are never unfollowed.

Does it work with X Premium and verified accounts?
Yes. Premium accounts can use the Fast preset, and Keep rules can protect verified accounts.

Does it work on twitter.com?
Yes, on both x.com and twitter.com, in Google Chrome.

## Privacy practices tab

**Single purpose**

```
Helps users manage who they follow on X (Twitter): find accounts that don't follow them back or have unfollowed them, and unfollow - or follow back - accounts in bulk.
```

**Permission justifications**

| Permission | Justification |
| --- | --- |
| Host: x.com, twitter.com | Reads the signed-in user's following and followers lists and sends unfollow and follow requests on x.com, in the user's own session, when the user starts a scan or a run. |
| Host: abs.twimg.com | Reads X's own web-app JavaScript files to find the request formats X's website currently uses. Nothing is executed from these files. |
| storage, unlimitedStorage | Saves settings, the whitelist, the last scan, the followers list used to see who unfollowed the user, groups and the follow/unfollow history locally, per X account. Large lists need more than the default quota. |
| alarms | Schedules the next unfollow, breaks and daily-limit pauses so a run survives the background worker being stopped. |
| scripting | Starts the extension's own content script in x.com tabs that were already open when the extension was installed or updated, so users don't have to reload X. |
| notifications (optional) | Requested only when the user turns on desktop notifications in Settings. Tells the user when a run reaches the daily limit, finishes or needs their attention, and when people unfollow them. Never used for ads or promotions. |

**Remote code:** No. All code is in the package.

**Data usage**

- Your following list, followers, whitelist, groups and history stay in local storage and are never sent anywhere.
- Anonymous usage statistics go to the developer's own server: a random install ID (not derived from the user or device), the extension version, install / daily-active / uninstall events, an aggregate count of follow/unfollow actions, and coarse country derived server-side from the request (the IP is not stored). No IP, X account, or personal data. Users can turn this off in Settings. In the data-collection checklist, tick **Location** (coarse country only); do **not** tick Personally identifiable information, Authentication information, Personal communications, Financial, Health, Web history, or Personal info - none are collected.
- Tick all three certifications: no selling to third parties, no use unrelated to the single purpose, no use for creditworthiness or lending.

Suggested wording for the analytics disclosure field:

```
This extension sends anonymous usage statistics to the developer's own server: a random install identifier generated on the device (not derived from the user or hardware and reset when extension data is cleared), the extension version, install / once-daily active / uninstall events, and an aggregate count of follow/unfollow actions. Approximate country is derived server-side from the network request; the IP address is not stored. No IP address, X/Twitter account, username, or following data is collected. Users can disable this in the extension's settings.
```
